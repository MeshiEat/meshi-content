Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки персональных данных пользователей мобильного приложения Meshi (далее — «Приложение») плательщиком налога на профессиональный доход Васильковым Данилой Александровичем, ИНН 244314842292 (далее — «Оператор»).

## 2. Какие данные обрабатываются

2.1. При регистрации локального аккаунта: никнейм, адрес электронной почты, пароль (хранится в виде хэша, в открытом виде не сохраняется и не передаётся).

2.2. При оформлении платной подписки (создание серверного аккаунта): адрес электронной почты, никнейм, аватар (если загружен пользователем).

2.3. Данные о питании, которые пользователь вносит в Приложение: рецепты блюд, содержимое холодильника, список покупок, календарь готовки, диетические предпочтения и аллергии — используются только для работы функций Приложения (расчёт списка покупок, подсветка аллергенов и т.п.) и не передаются третьим лицам, кроме случаев, предусмотренных разделом 4.

2.4. Технические данные: идентификатор устройства для push-уведомлений (FCM-токен), версия приложения, язык интерфейса.

2.5. Платёжные данные (номер карты и т.п.) Оператору не передаются и не обрабатываются — оплата производится непосредственно через платёжный сервис ЮKassa (ООО НКО «ЮMoney»), который является самостоятельным оператором персональных данных в части обработки платежа.

## 3. Цели обработки

3.1. Предоставление функциональности Приложения (в том числе синхронизация данных между устройствами участников одной семейной группы).

3.2. Обработка платежей за платную подписку.

3.3. Направление уведомлений, связанных с работой Приложения (в том числе push-уведомлений о событиях в семейной группе, при наличии согласия Пользователя на уведомления в настройках устройства).

3.4. Ответы на обращения Пользователя (в том числе запросы на возврат средств).

## 4. Передача данных третьим лицам

4.1. Данные для обработки платежа передаются платёжному сервису ЮKassa в объёме, необходимом для проведения платежа.

4.2. Данные о питании и профиле, внесённые Пользователем в рамках семейной группы, доступны только участникам этой же семейной группы — Оператор не использует их в иных целях и не передаёт третьим лицам.

4.3. Push-уведомления доставляются через сервис Firebase Cloud Messaging (Google) — идентификатор устройства (токен) передаётся этому сервису в объёме, необходимом для доставки уведомления.

4.4. В иных случаях персональные данные третьим лицам не передаются, за исключением случаев, предусмотренных законодательством РФ.

## 5. Хранение и защита данных

5.1. Данные хранятся на сервере Оператора, доступ к серверу ограничен.

5.2. Пароли хранятся в виде необратимого хэша.

5.3. Локальные данные Приложения (при использовании без платной подписки) хранятся только на устройстве Пользователя и Оператору не передаются.
