# История обновлений

Два независимых потока изменений: версии приложения (требуют установки APK) и обновления контента (блюда — докачиваются сами, без переустановки).

## Приложение

### 1.0.3 — 2026-08-18
- Безопасность: резервные копии Android (adb backup) больше не могут вытащить данные приложения без вашего ведома
- Безопасность: обновления приложения теперь проверяются по контрольной сумме (SHA-256) перед установкой — повреждённый или подменённый файл не установится

### 1.0.2 — 2026-08-18
- Скрыта системная панель навигации на устройствах с кнопками (не жестами) — свайп снизу вернёт её на время
- Переделаны окно и плашка предложения обновиться — раньше текст кнопки мог обрезаться/съезжать при переносе на новую строку
- Мелкие исправления интерфейса

### 1.0.1 — 2026-08-17
- В Настройках теперь видно установленную версию приложения
- Исправлена ошибка дублирования: если пользователь уже сам создал блюдо, а такое же потом пришло в обновлении контента — его рецепт больше не дублируется
- Добавлено окно "Что нового" — показывается один раз сразу после обновления

### 1.0 — 2026-08-17
- Первый релиз. Полностью локальный бесплатный план: календарь готовки, холодильник со списанием продуктов, список покупок, пошаговая готовка
- Локализация: русский, English, 日本語
- Автообновление блюд и приложения без переустановки
